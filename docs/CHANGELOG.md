# 原型交付更新

本版支持八种操作界面：简体中文、繁體中文、English、Tiếng Việt、日本語、한국어、Español、العربية。仅在设置页下拉框切换；已删除顶部 EN 按钮。阿拉伯语使用从右向左的页面布局。用户输入的姓名、笔记、原始转写不自动翻译。翻译为本项目的界面文案，不宣称经过官方认证或所有地区的母语审校。

设置顶部个人资料卡支持姓名和本地头像。人物关系档案支持改名、关系修正和备注；不覆盖历史转写中的原文。

会话可以改名，摘要、要点、决策、知识点、待办和补充笔记均可编辑，并加入最多四张图片。用户修改标记为“用户编辑”。原始转写与关系证据保持完整。

自由手记支持文字、图片、日程和专注计时。网页提醒需要页面保持开启；APK 使用 Android 原生本地闹钟和系统通知，仍受到权限、精确闹钟设置、强制停止和厂商省电规则影响。关闭工作空间保存会暂停原生后台提醒并取消已安排的闹钟。默认示例日程不安排原生闹钟。

本版没有真实麦克风采集、全天后台录音、语音识别、声纹身份识别、云端模型、照片 OCR、云同步或加密数据库。12 秒音频是合成提示音，示例转写与它不对齐。
