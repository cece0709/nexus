# NEXUS AI 交付使用说明

本次按“可上传网站”和“Android 手机 APK”两种方式交付，并附源码。实际编译、测试与真机结果以最终交付报告为准。这里的安装步骤不代表已经安装到你的手机或部署到你的 Cloudflare 账号。

## 文件用途

| 文件 | 用途 |
| --- | --- |
| `NEXUS-AI-Cloudflare.zip` | 已构建网站，上传 Cloudflare Pages；不需要先装开发工具 |
| `NEXUS-AI-Android-debug.apk` | Android 测试安装包，最低 Android 8.0；使用调试签名 |
| `NEXUS-AI-Source.zip` | 可修改前端、Android 原生工程、测试及说明；不含账号密钥 |

两个运行版本都保留录音演示标识。没有真实麦克风录音、ASR、说话人识别或云端模型。文字手记、改名、备注、主动选择的图片和日程是用户自行输入的本地内容。

## 上传 Cloudflare 网站

1. 登录 Cloudflare，进入 **Workers & Pages**，创建 **Pages** 项目。
2. 选择 **Direct Upload / Drag and drop** 上传方式。
3. 上传 `NEXUS-AI-Cloudflare.zip`，或上传解压后的文件夹内容。ZIP 根目录应直接看到 `index.html`、`assets/`、`_headers`，不要再套一层源码目录。
4. 部署后打开返回的 `pages.dev` 地址，核对主页、语言设置、人物网络、笔记与图片是否正常。

这个包已经构建好；直接上传不需要填写构建命令、后端地址或 API 密钥。详细说明及后续更新步骤见 [Cloudflare 部署说明](CLOUDFLARE_DEPLOY.md) 和 [官方 Direct Upload 文档](https://developers.cloudflare.com/pages/get-started/direct-upload/)。

网站数据保存在访问者当前浏览器中。换域名、浏览器或设备不会自动带走原数据，也不会与 APK 同步。网站没有关闭网页后的可靠手机通知；需要时可导出 ICS 到日历。

## 安装 Android APK

1. 将 `NEXUS-AI-Android-debug.apk` 发送到自己的 Android 手机并保存。
2. 从文件管理器打开，按系统提示允许这次安装来源。若手机由学校、企业或家庭管理，安装策略可能不允许侧载。
3. 安装后打开 **NEXUS**。首次使用不应要求麦克风权限；录音按钮运行的是演示。
4. 在设置页顶部更换头像、姓名和界面语言。进入日常手记添加内容；进入录音会话可改标题、编辑笔记或补充图片。
5. 需要日程通知时，主动点击应用内的通知授权入口，并在系统设置中允许通知。精确闹钟许可可用时使用精确调度，否则系统可能延迟通知。

这是调试签名原型，适合安装体验；不是应用商店正式发布包。后续发布应使用自己的受保护签名。若已有相同包名、不同签名的版本，Android 可能拒绝覆盖；不要为了安装而贸然卸载含有重要数据的旧版本，先保留需要的文字和照片。

APK 内置网页，可在没有网络的情况下使用当前本地功能。没有联网账号、云备份或实时同步。图片选择器、系统保存文件界面及通知设置由 Android 提供，机型表现可能不同。

### 提醒的实际范围

Android 代码已经接入本地 AlarmManager、通知权限和重启后的未来日程恢复；这与网站的页面内提示不同。系统强行停止、权限撤回、通知渠道关闭、厂商省电策略或不精确调度都可能阻止或延迟提醒。没有连接真机验证前，不保证锁屏到点提示，也不要将原型作为唯一的重要提醒来源。手机验收步骤见 [Android 工程说明](../android/README.md)。

专注计时仍由页面内存管理，刷新、关闭或进程被结束后不保证恢复；它不是独立的原生系统计时器。

## Windows 本地离线预览

解压源码包，进入含 `Start-NEXUS.cmd` 和 `dist/` 的项目目录。已提供构建产物时，双击 `Start-NEXUS.cmd`，保持窗口打开，再用浏览器访问 [本地预览](http://127.0.0.1:4173)。它需要 Node.js；启动器也支持这台电脑已有的 Codex Node 运行环境。按 `Ctrl+C` 停止。

若包内没有 `dist/` 或你修改了源码，先安装 Node.js 22.12+ 和 pnpm 10，然后运行：

```bash
pnpm install
pnpm test
pnpm build
pnpm preview
```

直接双击源码 `index.html` 不能运行 TypeScript 应用；通过 HTTP 服务预览即可，不需要云端服务。

## 保存与备份

- 保存开关开启时，文字及偏好写入当前工作空间，头像和图片附件存于本地 IndexedDB；没有应用级加密。
- JSON 导出包含文字、日程、人物与图片标识，不包含图片文件；照片需另外下载备份。
- 清空会移除当前工作空间、附件及原生待提醒记录；恢复示例会覆盖现有更改。操作前先导出需要保留的内容。
- 卸载 APK、清除应用数据、清理浏览器或换站点来源可能造成内容丢失；本地保存不等于备份。
