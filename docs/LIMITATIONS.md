# 能力边界与已知限制

本版本包含浏览器产品原型与 Android 本地宿主，预置人物、对话、笔记和关系均为虚构。用户主动填写的手记、日程、人物备注、笔记更改及选择的头像照片可能是真实个人内容，需要按本地数据边界保管。“已实现”表示代码与相应交互存在；编译、浏览器检查和手机真机检查是不同的验证层次，以交付报告为准。

## 音频与时间线

合成提示音的波形用于试听交互。会话上的几十分钟时长及逐字文本是示例元数据，不是提示音的真实内容。不能点击文本并听到该句原音；当前没有音文强制对齐，也没有完整原始会话音频。

模拟计时依赖浏览器事件循环，后台页可能被节流或挂起；它不是音频采样时钟，不用于证明长时连续录制。保存时将脚本排布到至少 90 秒的演示时间线，不意味着真的录制了 90 秒。关闭页面会结束本次演示状态，不会在系统中继续采集。

## 推断与搜索

规则输出的“置信度”是解释演示的分值，未经校准，不代表真实概率或准确率。场景规则可能把关键词相同的闲聊判成会议，不能用于无人审核的正式记录。

人物和说话人的映射来自示例。关系分数、颜色、轨道半径、连线和节点距离都不能说明真实身份、感情亲疏或人格特征。关闭“新关系需要手动确认”会影响演示候选的确认状态，不会启用真实身份识别。

搜索支持一定同义词与人物匹配，不能完整理解任意中文问句、精确日期逻辑、复杂否定或多跳关系。结果可能漏检或误检；需要阅读原文来源。当前没有向量嵌入、重排模型、联网检索或生成式问答。

结构化笔记不是生产级抽取器。当前笔记要点以字符串保存，没有每项独立的转写版本/引用 ID；决定、任务及负责人仍需核对。用户可修改生成笔记，保存后标记为用户编辑；没有修改历史或逐条差异审计。原始转写及关系引文不会因此改写。

## 日常手记、照片与提醒

图片附件不是“录音已接入”的证明。相机按钮使用系统文件选择器，是否显示拍照入口由浏览器/设备决定；没有自动拍摄、相片识字、自动识别人脸或去除 EXIF 元数据。每张 2 MiB、每篇 4 张是当前应用限制；没有固定工作空间总量上限，浏览器配额不足仍会失败。

工作空间 JSON 包括日记文字和照片 ID，不包括照片文件；导出 `.txt` 也不包括图片。完整保留照片需单独下载，清除浏览器站点数据会影响本地照片。当前没有加密图片库或自动云备份。

日历输入和页面展示采用 UTC+8，ICS 使用 UTC 时间点；导入日历后显示随接收端时区变化，用户应核对时间。`notified` 是应用已处理到期提示的状态，不代表用户完成了事情，也不代表手机收到通知。

网站只有网页存活期间才检查提醒和计算专注结束；导航到其他产品页面可以继续，刷新/关闭网页不保证保留正在进行的计时。浏览器节流、休眠、系统静音与通知限制可能延迟或阻止展示。浏览器通知权限由用户点击后请求；授权状态也不保证所有手机支持页面直接创建通知。[Notifications API 限制](https://developer.mozilla.org/en-US/docs/Web/API/Notifications_API/Using_the_Notifications_API)

ICS 导出带事件开始时的 `VALARM` 显示提醒，但导入方可忽略提醒，设备通知仍取决于用户设置。Android APK 的原生本地日程是另一条路径，代码可向系统注册提醒，但没有真机结果前不保证锁屏展示；强行停止、通知渠道关闭、权限和厂商电池策略仍会影响。没有手机日历双向同步或远程推送服务。专注工具帮助安排时间，不承诺治疗或医学效果。

## 数据与隐私

- `localStorage` 未加密、无登录。共享同一浏览器配置、浏览器扩展、开发者工具或站点脚本可能访问数据。
- 本地保存不等于安全备份。清理浏览器、无痕窗口关闭、换浏览器、换配置文件或换站点域名都可能使状态丢失。
- 关闭“记住工作空间”会移除内容保存副本，只保留不含正文的保存关闭标记；刷新后重新载入应用自带的示例且保持保存关闭。清空的是当前工作空间，不是从软件包中抹除虚构示例。
- 导出的 JSON 是明文，可能包含用户修改过的文字；用户自行保管。音频提示音单独导出，不包含真实录音。
- 本地保存格式验证覆盖嵌套字段、唯一 ID、时间/数值范围、人物引用、关系证据来源及日记/日程结构；为旧 v1 内容补入语言和日常记录字段，但没有完整的跨版本模式迁移、导入恢复、多标签页冲突处理或跨设备一致性协议。
- 隐私设置不是系统权限控制。没有麦克风授权，不会因为点击设置就具备后台录音、加密或云端处理能力。

## 可视化与平台

3D 显示依赖浏览器 WebGL 与驱动。低性能设备、远程桌面及关闭硬件加速的环境可能使用降级视图或出现帧率下降。原型以小规模示例网络验证交互，尚未以成千上万人物进行性能验证。

桌面布局优先；窄屏提供响应式排版，Android 宿主也处理系统栏与文件选择，但没有真机结果前不声称已通过所有手机适配、后台生命周期或辅助技术兼容性验收。没有 iOS 应用。图谱动画可减少，人物名单保留文字交互入口。
